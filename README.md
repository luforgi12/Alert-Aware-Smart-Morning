# Alert-Aware Smart Morning

Застосунок для розумного ранкового пробудження: налаштовуйте будильники та стежте за повітряними тривогами у вибраному регіоні України.

## Опублікований сайт

### [Відкрити Alert-Aware Smart Morning на GitHub Pages](https://luforgi12.github.io/Alert-Aware-Smart-Morning/)

## Головні функції

- Цифровий годинник і дата українською мовою.
- Кілька будильників із вибором часу, назви та днів повторення.
- Власна мелодія будильника та відкладення сигналу.
- Статус повітряної тривоги для вибраної області або району.
- Налаштування перенесення будильника під час червоної та жовтої тривоги.
- Системні сповіщення, темна/світла тема та режим запобігання вимкненню екрана.

## Локальний запуск

Потрібен Node.js і npm.

```bash
npm install
npm run dev
```

Для production-збірки виконайте:

```bash
npm run build
```
